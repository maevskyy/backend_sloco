## Замечания

- Доки Кирилла подробные и в целом честные: у каждой задачи статус, дата live-верификации, что не сделано. Стиль «спека = задача» совпадает с тем, как ведётся репо.
- `CURRENT_STATE.md` gateway — теперь главный документ «что есть на проде»; его надо обновить после переключения деплоя на `main` и после SLO-4/5/7 (там ещё старые тайминги).
- `docs/README.md` рекомендера и gateway ссылаются друг на друга и на корень корректно только при текущем расположении файлов — ещё одна причина двигать корневые доки одним коммитом, а не по одному.
