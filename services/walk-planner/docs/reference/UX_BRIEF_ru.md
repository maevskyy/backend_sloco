# Walk Planner — бриф для UI/UX-дизайна

Документ для дизайнера и для Claude Design: что умеет планировщик пеших прогулок, что пользователь вводит,
что получает на выходе, какие бывают состояния и тексты. Описано то, что **реально работает** в тестовом
дашборде (Streamlit) на данных Бухареста. Раздел 10 — предложение по экранам мобильного приложения;
раздел 11 — что есть только в тестовом стенде и переносить не нужно.

---

## 0. Коротко

**Что это.** Пользователь говорит: «я гуляю в субботу с 10:00 до 18:00, хочу достопримечательность, кофе,
парк и ужин». Планировщик подбирает конкретные места и строит **пеший маршрут по улицам** с расписанием:
куда идти, во сколько прийти, сколько там пробыть, когда закончишь. Учитывает часы работы заведений на
момент прихода, длину окна, стиль прогулки. Выдаёт **несколько вариантов** на выбор, маршрут можно
**поправить руками** (перетащить, убрать, добавить место, поменять время), а потом **открыть в Google / Apple
Maps** и идти по навигатору.

**Для кого.** Турист или житель, который идёт пешком и хочет готовый план на день / вечер без ручного
составления.

**Ценность.** Не «список мест», а готовый маршрут-расписание, который реально пройти: места открыты,
время сходится, по улицам, с навигацией.

## 1. Термины

| Термин | Что значит |
|---|---|
| **Окно** | Время прогулки: от «Выхожу в» до «Закончить к». Может переходить через полночь. |
| **Слот (активность)** | Тип остановки, который хочет пользователь: «Достопримечательность», «Кофе», «Парк / природа», «Еда / ресторан» и т.д. Пользователь задаёт **упорядоченный список** слотов — это порядок прогулки. На каждый слот планировщик подбирает одно конкретное место. |
| **Место по пути** | Дополнительная короткая остановка (до 10 мин), которую планировщик добавляет, если окно длиннее, чем нужно на слоты. Можно зайти, а можно пройти мимо. Помечается «по пути, можно пройти мимо». |
| **Ваше место (📍)** | Место, которое пользователь сам выбрал из базы: «Обязательно зайти» при создании или «Добавить место» при редактировании. Всегда остаётся в маршруте. |
| **Вариант** | Один из нескольких альтернативных маршрутов по одному запросу (по умолчанию 3). |
| **Стиль** | Как использовать время: «Максимум мест», «Размеренный», «Живописный». |
| **Форма** | «В одну сторону», «Петля» (вернуться к старту), «По району» (без точки старта). |
| **Остановка** | Место в построенном маршруте с конкретным временем прихода и ухода. |
| **Отрезок** | Пеший переход между двумя соседними точками (время, км, линия по улицам). |

---

## 2. Основной сценарий

1. Пользователь задаёт **когда** (день, начало, конец), **откуда** (точка старта), **что хочет** (слоты по
   порядку), **стиль** и **форму** маршрута. Остальное — по умолчанию.
2. Нажимает **«Построить маршрут»** → 1–5 секунд расчёта.
3. Видит **варианты** (по умолчанию 3) — сравнивает: сколько мест, сколько км, во сколько финиш.
4. Открывает вариант: **карта** с линией по улицам и номерами, **сводка**, **предупреждения**, **расписание
   остановок** с фото и описаниями.
5. При желании **редактирует**: меняет порядок перетаскиванием, убирает, добавляет своё место, меняет
   сколько где побыть — время и маршрут пересчитываются сразу.
6. Нажимает **«Открыть в Google Maps»** (или Apple Maps по отрезкам) и идёт по навигатору.

## 3. Входные параметры

Колонка «Уровень» — рекомендация для приложения: **основной** (видно сразу), **расширенный** (спрятать в
«Ещё / Настройки»), **стенд** (только для тестов, в приложение не переносить).

| Параметр | Что значит | Значения / по умолчанию | Уровень |
|---|---|---|---|
| **Город** | Где гуляем | Сейчас в данных только Бухарест | основной (скрыт, пока город один) |
| **День** | Дата прогулки → день недели для часов работы | Дата, по умолчанию сегодня | основной |
| **Выхожу в** | Начало окна | Время с шагом 15 мин, по умолчанию 10:00 | основной |
| **Закончить к** | Когда вернуться к старту (петля) или быть в последней точке | Список с шагом 15 мин от времени выхода до +24 ч; после полуночи — пометка «(+1 день)». По умолчанию выход + 4 ч. «00:00 (+1 день)» = до полуночи; 00:00 → 00:00 (+1 день) = сутки | основной |
| **Старт** | Откуда начинаем | В стенде: центр района / выбрать место из базы / координаты. В приложении логично: **моё местоположение**, место из поиска, точка на карте. Для формы «По району» старта нет | основной |
| **Слоты активностей** | Что хочу и в каком порядке | Упорядоченный список из 8 типов (ниже). По умолчанию: Достопримечательность → Кофе → Парк / природа → Еда / ресторан. Сейчас каждый тип можно выбрать один раз | основной |
| **Стиль** | Как использовать свободное время | «Максимум мест» (по умолч.), «Размеренный», «Живописный» — см. §4.4 | основной |
| **Форма** | Геометрия маршрута | «Петля» (по умолч.), «В одну сторону», «По району» | основной |
| **📍 Обязательно зайти** | Конкретные места из базы, которые должны быть в маршруте | Мультивыбор с поиском по названию. Необязательно | расширенный (или основной — на усмотрение) |
| **Вариантов маршрута** | Сколько альтернатив построить | 1–5, по умолчанию 3 | расширенный |
| **Радиус района (км)** | Как далеко от старта искать места | Любое число ≥ 0.3, по умолчанию 2.5. Если за окно столько не пройти, радиус **сам сужается** до досягаемого (с пояснением) | расширенный |
| **⏱ Сколько времени на месте** | Длительность визита по типам слотов | Для каждого выбранного типа: «авто» (оценка по самому месту) или своё: 10, 15, 20, 30, 45 мин, 1 ч, 1 ч 15, 1 ч 30, 2 ч, 2 ч 30, 3 ч, 4 ч | расширенный |
| **Добавлять места по пути** | Заполнять свободное время короткими остановками | Вкл по умолчанию | расширенный |
| **Только места с известными часами работы** | Исключить места без расписания | Выкл по умолчанию | расширенный |
| **Интересы: любимые места** | Персонализация подбора по вкусу | Мультивыбор мест из базы. В приложении — брать из профиля / онбординга, а не спрашивать в форме | стенд → профиль |
| **Кандидатов на слот** | Из скольких мест выбирать на каждый слот | 4–20, по умолчанию 8 | стенд (настройка алгоритма) |

**Типы слотов (8):** Достопримечательность · Кофе · Еда / ресторан · Бар / напитки · Парк / природа ·
Рынок / площадь · Развлечение · Шопинг. Для иконок: достопримечательность (музеи, храмы, памятники), кофе,
ресторан, бар, парк, рынок/площадь, развлечения (театр, кино, активности), магазины/сувениры.

## 4. Что делает планировщик (логика, которую нужно понимать для дизайна)

### 4.1 Подбор мест
- На каждый слот берутся **популярные места в досягаемом районе + лучшие рядом со стартом**, затем
  оптимизатор выбирает по одному месту на слот так, чтобы было интересно и без лишней ходьбы.
- Популярность — по рейтингу и числу отзывов Google (или по «любимым местам» пользователя, если заданы).
- **Слоты идут в заданном порядке.** Оптимизатор их не переставляет — порядок меняет только пользователь
  в редакторе.
- Одно место никогда не повторяется в маршруте.
- Места, которые Google отмечает **закрытыми навсегда / временно**, никогда не предлагаются.

### 4.2 Время и радиус
- Скорость ходьбы ~4.5 км/ч, переходы считаются **по реальным улицам**. Один переход в плане — не
  длиннее ~45 мин.
- **Радиус** можно задать любой: если за окно столько не пройти (учитывая время на сами места и, для
  петли, дорогу обратно), поиск сужается до досягаемого района, и пользователь видит пояснение.
- Маршрут **укладывается в окно**. Если все слоты не помещаются, лишние отбрасываются (с сообщением,
  какие). Если не помещается даже одна остановка — показывается полный маршрут с пометкой «не успеваю».
- **Длинное окно используется**, а не просто «влезает»: чем больше свободного времени, тем охотнее
  маршрут идёт к сильным местам дальше от старта, плюс добавляются места по пути (§4.5).

### 4.3 Часы работы
- Проверяются **на момент, когда маршрут доходит до места**, по дню недели.
  Пример: прогулка 16:00–22:00, кофейня работает до 18:00. Если слот «Кофе» приходится на ~16:30 —
  она в маршруте; если на ~20:00 — берётся другая, открытая в это время.
- Место должно быть открыто **весь визит**. Если до открытия ≤ 30 мин — планировщик ставит ожидание
  («⏳ приходим в 09:50, ждём открытия 10 мин»).
- Часы есть примерно у 64% мест. Места без часов считаются открытыми и помечаются «часы работы неизвестны»
  (есть опция исключить их).
- Бывают ночные часы (бар 18:00–02:00), круглосуточные, перерывы, выходные дни.

### 4.4 Стиль
| Стиль | Поведение |
|---|---|
| **Максимум мест** | Плотный маршрут: заполняет до ~95% окна местами по пути. |
| **Размеренный** | Визиты на 30% дольше, мест по пути меньше (заполняет до ~75% окна) — остаётся свободное время. |
| **Живописный** | Больше ходьбы; места по пути — парки и площади; заполняет до ~90% окна. |

### 4.5 Места по пути
- Если окно длиннее, чем нужно на слоты, планировщик добавляет **короткие остановки по дороге** — тех же
  (не «еда») типов, что выбрал пользователь; у «Живописного» — парки и площади.
- Каждая — **до 10 минут**, можно просто пройти мимо. Повторы типа допустимы (несколько церквей подряд — ок,
  если они по пути).
- Порядок слотов пользователя сохраняется; места по пути вставляются между ними.
- Отключается переключателем «Добавлять места по пути».
- В длинном окне их может быть много (на 14 часов — до ~25–30 коротких остановок).

### 4.6 Время на месте
- По умолчанию оценивается **по самому месту**: памятник, статуя, колокольня, площадь — 10–15 мин;
  маленький сквер — 10; крупный парк — 50–60; большой музей — до 90; кофе — 30; ресторан — 75; бар — 60.
- Пользователь может задать своё время **по типу** (в форме) или **на конкретной остановке** (в редакторе).
  Своё время планировщик не меняет.

### 4.7 Обязательные места (📍)
- Всегда в маршруте, в любом варианте. Вставляются туда, где стоят меньше всего времени и открыты.
- Если место в этот день закрыто или не помещается — оно **всё равно остаётся**, с предупреждением
  (пользователь может знать больше, чем данные).
- Остальные слоты подстраиваются под оставшееся время.

### 4.8 Варианты
- До 5 вариантов на один запрос. Каждый следующий старается взять **другие** места.
- Если подходящих мест мало, вариантов может получиться меньше — с пояснением.

## 5. Что пользователь получает на выходе

### 5.1 Выбор варианта
Переключатель «Вариант 1 / 2 / 3» и строка-сводка по каждому:
`Вариант 1: 5 мест · 0.7 км · до 13:43 · Вариант 2: 5 мест · 1.3 км · до 13:50 · …`
Если вариант правили руками — пометка «✏️ изменён».

### 5.2 Сводка выбранного варианта (4 показателя)
| Показатель | Пример | Смысл |
|---|---|---|
| **Остановок** | `4 из 4 + 2 + 📍1` | слотов заполнено из запрошенных + места по пути + ваши места |
| **Финиш / Возвращение** | `13:43` и `+17 мин запаса` или `−33 мин, не успеваю` | «Возвращение» для петли, «Финиш» для остальных |
| **Пешком** | `3.0 км · 0:36` | всего пройти, км и часы:минуты |
| **Окно** | `10:00–14:00` (или `22:00–01:00⁺¹`) | заданное окно |

### 5.3 Карта
- Линия маршрута **по улицам** (анимированная), зелёный маркер старта, **нумерованные** остановки.
- Тап по остановке — попап: номер, название, время `10:08–10:53 · осмотр 45 мин`, фото.
- (Стенд дополнительно рисует круг «район поиска» и серые точки-кандидаты — это отладка.)

### 5.4 Расписание остановок (основной контент)
Для каждой остановки:
- **Номер и название** (`2. Artmark`)
- **Тип**: название слота («Кофе») / «Достопримечательность · по пути, можно пройти мимо» / «📍 ваше место»
- **Время визита**: `11:03–11:33 · осмотр 30 мин`
- **Ожидание** (если есть): `⏳ приходим в 09:50, ждём открытия 10 мин`
- **Часы в этот день**: `🕒 сб 10:00–18:00` / `сб круглосуточно` / `сб закрыто` / `сб до 02:00` (ночь после вчера) / `часы работы неизвестны`
- **Предупреждение** (если есть): `⚠️ по графику в это время может быть закрыто — маршрут построен как есть`
- **Карточка места**: главное фото + до 3 миниатюр (тап — на весь экран), название, тип
  (`historic church bell tower`), рейтинг `★ 4.8 (6)`, ссылка «Open in Google Maps», короткое описание.
- Между остановками в данных есть отрезки: `пешком N мин · X км` — в стенде их нет в списке, в
  приложении стоит показывать в таймлайне.

### 5.5 Навигация
- Кнопка **«🗺 Весь маршрут в Google Maps»** — пешеходный маршрут со всеми точками (на телефоне открывает
  приложение Google Maps).
- Если точек больше 9 (ограничение Google), маршрут делится на части: **«Часть 1/2», «Часть 2/2»** — часть
  N заканчивается там, где начинается N+1.
- **По отрезкам**: для каждого перехода «Старт → Artmark» ссылки **Google** и **Apple Maps**.

## 6. Редактирование готового маршрута

Включается переключателем «✏️ Изменить маршрут». Правки относятся к выбранному варианту; каждая правка
сразу пересчитывает время, маршрут по улицам, карту, навигацию и предупреждения.

| Действие | Как сейчас в стенде | Что происходит |
|---|---|---|
| **Поменять порядок** | Перетаскивание в списке «🚶 Маршрут» | Порядок списка = порядок прогулки. Можно одним жестом первое место сделать последним |
| **Убрать место** | Перетащить в «🗑 Не заходить» или выбрать в списке «➖ Убрать место» | Место уходит в корзину, его можно перетащить обратно |
| **Добавить место** | «➕ Добавить место из базы» — поиск по названию + «Добавить» | Встаёт в лучшую позицию (меньше всего времени, открыто), помечается 📍; дальше можно двигать |
| **Сколько побыть** | Таблица «⏱ Сколько побыть на каждом месте», минуты по каждой остановке | Всё время сдвигается |
| **Вернуть как было** | «↺ Вернуть маршрут планировщика» | Откат всех правок этого варианта |

**Важный принцип:** в ручном режиме планировщик **ничего не выкидывает и не заменяет**. Если место к новому
времени закрыто или маршрут вылезает за окно — показывается предупреждение, но маршрут строится
(пользователь может знать, что сегодня место работает дольше).

Если форму поменяли после построения — над маршрутом: «Параметры изменились — нажмите «Построить
маршрут», чтобы пересчитать. Ниже прошлый маршрут.»

## 8. Состояния экрана и тексты (текущие формулировки)

**Пусто / до построения:** форма и кнопка «🧭 Построить маршрут». Если нет ни одного слота и ни одного
обязательного места: «Добавьте хотя бы один слот активности или место, куда обязательно зайти.»

**Загрузка:** 1–5 с (подбор + маршрут по улицам для каждого варианта).

**Пояснения (info):**
- «Радиус 20 км сужен до 1.4 км: за окно 10:00–14:00 дальше не успеть — ~190 мин уходит на сами места, и нужно вернуться к старту.»
- «Радиус … сужен до 0.4 км: на все слоты нужно ~190 мин, это больше окна (180 мин), поэтому ищу рядом со стартом, а слоты, которые не влезут, отпадут.»
- «Разных маршрутов получилось 2 из 3: подходящих мест мало — расширьте радиус, окно или число кандидатов на слот.»
- «Стиль «Максимум мест»: по пути добавлено мест — 10, чтобы занять окно 10:00–00:00 (+1 день). Только выбранные слоты — выключите «Добавлять места по пути».»

**Предупреждения (warning):**
- «Не нашлось мест, открытых в это время в радиусе, для слотов: Кофе — увеличьте радиус или окно, или смените точку старта.»
- «Не поместилось в окно: Еда / ресторан. Остальное уложено до 14:00; чтобы вернуть слоты, раздвиньте окно.»
- «Маршрут займёт ~258 мин, а окно 240 мин: финиш в 14:18, позже 14:00.»
- «⚠️ «Artmark» — в 20:33 по графику закрыто (сб 10:00–20:00). Маршрут всё равно построен: оставьте, если знаете, что сегодня работает дольше.»
- «⚠️ «Artmark» — закрывается раньше, чем закончится визит 19:17–20:02 (сб 10:00–20:00). Маршрут всё равно построен: …»

**Ошибки (маршрута нет):**
- «Кандидатов не найдено — расширьте радиус или окно времени.»
- «Не удалось собрать маршрут: к моменту, когда до них можно дойти, кандидаты закрыты или не помещаются в окно. Сдвиньте время или смените слоты.»

**Редактор:** «В маршруте не осталось мест — перетащите что-нибудь обратно или добавьте место.»

## 9. Ограничения данных и крайние случаи (для дизайна)

- **Один город** (Бухарест, ~13 тыс. мест: еда ~8.9 тыс., достопримечательности ~2.5 тыс., развлечения ~1 тыс., шопинг ~570).
- **Нет фото** у ~4% мест → нужна заглушка.
- **Часы неизвестны** у ~36% мест → отдельное состояние «часы работы неизвестны».
- **Длинные названия** на румынском с диакритикой, иногда в кавычках.
- **Описания на английском** (интерфейс — русский). Решить, как это смотрится, или планировать перевод.
- **Ночные окна** (22:00–01:00): время со следующего дня показывается как `00:30 (+1)`; окно — `22:00–01:00⁺¹`.
- **Много остановок** (длинное окно + места по пути: 15–30 точек) → длинный таймлайн, навигация частями.
- **Маршрут вылез за окно** (ручные правки, обязательное место далеко) → отрицательный запас.
- **Место закрыто** на момент визита (ручные правки / обязательное место) → предупреждение на карточке и сверху.
- **Мало вариантов** (меньше запрошенных), **ни одного** — ошибка.
- **Праздники** не учитываются — часы это обычное недельное расписание.
- Переходы — **только пешком** (транспорта нет).

## 10. Предлагаемые экраны для мобильного приложения

Это предложение по структуре, не финальный дизайн.

**1. «Новая прогулка» (настройка)**
- Когда: день · с … до … (с явной пометкой «+1 день» после полуночи); быстрые пресеты («2 часа», «до вечера», «весь день»).
- Откуда: моё местоположение (по умолчанию) / найти место / точка на карте; форма: петля / в одну сторону / по району.
- Что хочу: чипы активностей с иконками, **перетаскиваемые** (порядок = порядок прогулки), «+» добавить тип.
- Стиль: 3 карточки с короткими пояснениями.
- «Ещё»: обязательно зайти (поиск), время на месте по типам, радиус, места по пути, только с известными часами, число вариантов.
- CTA «Построить маршрут».

**2. «Варианты»**
- Карусель или список карточек: мини-карта, `N мест · X км · до HH:MM`, запас/опоздание, 2–3 главных места (фото), бейджи предупреждений (часы, не помещается).

**3. «Маршрут» (детали варианта)**
- Карта сверху (сворачиваемая), сводка из 4 показателей, предупреждения.
- Таймлайн: остановка (фото, название, тип-бейдж: слот / по пути / 📍, `11:03–11:33 · 30 мин`, часы сегодня, ожидание, ⚠️) → отрезок `пешком 6 мин · 450 м` → следующая остановка → … → возвращение.
- CTA «Начать навигацию» (Google / Apple Maps; «Часть 1/2»…), «Изменить».

**4. «Редактирование»**
- Список с drag-handle, свайп «убрать» (корзина «Не заходить» с возвратом), степпер минут на каждой остановке, «+ Добавить место» (поиск), «Вернуть как было».
- Живой пересчёт сводки и предупреждений при каждой правке.

**5. «Место» (детали)**
- Галерея, название, тип, рейтинг, описание (короткое + разделы), часы (сегодня + неделя), адрес, «Открыть в Google Maps».
- Действия в контексте маршрута: «Сколько побыть», «Убрать из маршрута»; из поиска — «Добавить в маршрут», «Обязательно зайти».

**6. Поиск места** — общий для «Обязательно зайти» и «Добавить место»: поиск по названию, карточки с фото/рейтингом/типом.

**Общие состояния:** загрузка расчёта, пустой результат, ошибки (§8), «параметры изменились — перестроить».

## 11. Только в тестовом стенде — не переносить

- «Кандидатов на слот» (настройка алгоритма).
- Старт «Координаты» и «Центр района» (в приложении — геолокация / поиск / точка на карте).
- На карте: круг «район поиска» и серые точки-кандидаты.
- «Интересы: любимые места» как поле формы (в приложении — из профиля).
- Боковое меню дашборда и его настройки.
